# Growth Model Input

This folder stores the active source workbook for Part-1 growth modelling.

## Active workbook

- `2026_global_raw_data_20260601.xlsx`

The workbook provides:

- geological storage capacity estimates
- country/region-level 2030 cumulative storage
- country/region-level 2030 storage rates
- published policy targets
- IPCC low/high demand point targets

The active country and region pool is:

- UK
- US
- EU (`EU without UK` sheet)
- China
- Middle East
- Australia
- Canada
- Indonesia
- Thailand
- Brazil
